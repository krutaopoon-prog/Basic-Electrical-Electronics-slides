# วิชางานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น 20100-1005 (ปวช.)

สื่อการสอนแบบเว็บ (static site) สำหรับ GitHub Pages แยกเป็นรายสัปดาห์: สไลด์ แบบฝึกหัด แบบทดสอบ ใบงาน และหน้าเฉลยสำหรับครู

- `index.html` หน้าแรก
- `w01/slides.html` สไลด์สัปดาห์ที่ 1 (← → / Space, T = สารบัญ, F = เต็มจอ)
- `w01/exercises.html` แบบฝึกหัด (ตรวจทันที, พิมพ์ใบงาน A4)
- `w01/quiz.html` แบบทดสอบ 20 ข้อ ก่อน/หลังเรียน
- `w01/worksheet.html` ใบงานที่ 1.1 สำหรับพิมพ์ใช้ในโรงฝึกงาน
- `w01/answers.html` เฉลยสำหรับครู (ต้องใส่รหัสครู)

## แก้เฉลย / เปลี่ยนรหัสครู
1. แก้ `_private/answers-w01.json`
2. รัน `node _private/encrypt-answers.mjs w01 "รหัสใหม่"` (ต้องมี Node.js 18 ขึ้นไป)
3. อัปโหลดไฟล์ `w01/answers.enc.js` และ `w01/check-data.js` ใหม่

โฟลเดอร์ `_private/` และ `บทเรียน/` อยู่ใน `.gitignore` — ห้ามอัปขึ้น GitHub
